# Extravagant Works — GitHub Pages concept

The static GitHub Pages edition of the independent website concept at [glasscityi.com/bobross](https://glasscityi.com/bobross), created by Glass City Intelligence.

Live site: **https://dmcconaughy.github.io/bobross/**

## Hosting

GitHub Pages publishes `main` from the repository root. `.nojekyll` preserves the compiled Astro stylesheet directory. All artwork, fonts, and icons are included, and asset paths are relative so they work beneath `/bobross/`. No server, API, secrets, build dependency, or paid service is required to serve this copy.

This is a static snapshot. Changes merged here publish automatically. Changes to the original GCI site must be exported and reviewed here separately.

## Experience

The original content, visual design, official studio links, mobile navigation, FAQ, and browser-local painting canvas are preserved. The canvas supports pointer and keyboard drawing, five colors, clearing, and PNG download. Drawings are temporary and stay in the browser.

The canonical URL continues to identify the original GCI concept; the social sharing URLs identify this copy. The `noindex, nofollow, noarchive` meta tag is preserved. Search exclusion is not access control. GitHub Pages cannot serve the original Vercel visit API, so this edition does not load GCI visit or Clarity tracking scripts.

## Verification

Before publication, the static export was built from the current concept and checked at 1440, 390, and 320px: asset loading, no horizontal overflow, one primary heading, noindex, mobile menu, FAQ, pointer and keyboard drawing, palette selection, clearing, PNG download, and uncaught browser errors. Navigation and fallback content were also checked with JavaScript disabled. The deployed Pages site must be inspected after publication.

## Limits

This is an independent concept, not the studio's official site or booking system. It is not affiliated with Bob Ross Inc. The October and November 2026 class listings are a dated snapshot; the studio's official schedule remains authoritative. There are no booking forms, payments, or backend services.
